Turning this into a tool

Tarkov raid planner

Connect your EFT Logs folder, and the site shows which quests you can do on each map right now, plans the raids, and tells you what to bring and what to keep. Data comes from tarkov.dev and the wiki. Your progress comes from the game's own logs, read only from your computer.

Things to get right early

Patches break data

Quest text, givers and spawns change between wipes. Version the snapshot and show the "verified on" date next to every fact.

Licensing

Fandom text is CC BY-SA and needs attribution. The community map images carry their own licenses (re3mr's are CC BY-NC-SA). Link to them or draw your own schematics, as this page does.

Stay outside the game

Read only the Logs folder the user picks, plus public data. Never read game memory or network traffic, and never automate the client.

Scope details, recent events and corrections

    Add a profile / wipe

    Leave the start empty to use a manually confirmed quest list. Logs stay in history until you confirm a boundary. For log tracking, use the profile ID shown by Scan past sessions or Import logs folder. A version change alone does not prove a wipe.

    Review log history and legacy progress

    Confirm current quests on this map

    Paste one quest name per line from your current in-game list for this map. This replaces current membership for quests located on this map only; multi-map quests keep their logged status. Other quests are removed from Current quests without marking them completed or failed. Later starts and completions still update the list.

    Logs record starts, failures and completions, not kills or hand-ins. Current quests uses only the chosen profile and wipe, or quests you confirm by hand. Missing profile or mode stays in history. Completed prerequisites are implied within this scope. The site reads only your chosen Logs folder and never writes to it.

    Raid mode
    Keyboard shortcuts

    In raid mode, Ctrl + Shift + ← / → steps through your selected quests while this page has focus. For controls while Tarkov has focus, install the optional quest shortcuts extension and choose this tab from its toolbar button. Browsing never checks off objectives.
